ChequeGuardAI

Intelligent Cheque Deposit System

  • Built a compliance-oriented cheque processing engine aligned with Payments Canada Rules A4/A10: a deterministic decision pipeline covering validation, duplicate detection, fraud scoring, hold calculation and ledger posting, with an 18-case evaluation suite.
  • Added a 3-agent Gemini LLM pipeline that generates explanations for both the customer and the operations team; the LLMs narrate and advise, but never override the compliance rules.
  • Every run is logged to a Google Sheets tab with a trace ID and the details of each step (input, output, duration and outcome).
  • Each outcome is formatted as ISO 20022-structured messages (pacs.002, pacs.004 and camt.054, as applicable), with A4 codes mapped to ISO return reasons; the delivery channel is simulated.
  • Google Apps Script
  • Gemini API
  • Google Sheets

Reconciliation

Payroll Reconciliation Engine

  • Built a reconciliation tool for payroll-deducted loan and savings payments: it matches expected against actual amounts by member and product, flags differences, detects changes relative to previous periods and generates Excel reports with audit trails.
  • Runs entirely in the browser through Pyodide (client-side Python/pandas), with no backend, in a single HTML file that works offline, designed for non-technical payroll analysts.
  • Exceptions are resolved in 4 queues, individually or in bulk, and each analyst decision is recorded in the audit trail with a timestamp, the action and the applied value.
  • Reference capacity: about 200,000 total rows with 8 GB of RAM; files are processed locally and never leave the computer.
  • Python
  • Pandas
  • Pyodide
  • GitHub Pages

Fraud Exploration

Fraud Exploration Board

  • Built an AML/fraud analytics engine on a risk and compliance dataset with dirty data: an audited cleaning pipeline that feeds a three-tier Isolation Forest anomaly-detection model (transaction, account and customer), able to identify transaction splitting (structuring), unresolved sanctions-list matches and account control failures.
  • Added a 5-agent Gemini pipeline (Compliance Sentinel) that interprets the scores and turns them into a risk verdict and a single action within a fixed six-level ladder. Evidence strength is computed in code and caps the action's severity, so the LLMs advise but never decide.
  • The serving layer is Postgres (Supabase) with row-level security: the public key allows reads only (SELECT) and write privileges are revoked.
  • The account-level model is exported to JSON and recomputed in the browser, without libraries, to verify the served scores.
  • PostgreSQL
  • Python
  • Power BI
  • ML
  • LLM

Sentinel

Card Fraud Detector

  • Card-fraud detector on the public IEEE-CIS dataset (590,540 transactions × 434 columns, 3.5% fraud): XGBoost with customer-level features fitted on training data only, evaluated with a time-based split and PR-AUC as the headline metric.
  • On validation: PR-AUC 0.589 vs. a 0.547 baseline, precision 0.74 and recall 0.49 at a tuned 0.66 threshold (ROC-AUC 0.90). The ~0.94 commonly seen on Kaggle is deliberately rejected, since much of it comes from customers repeated across train and test; a level with union-find graph features and an ensemble did not improve PR-AUC and was not promoted to production.
  • FastAPI inference service (/predict and /explain, with the top SHAP contributions per transaction) and a Google Apps Script dashboard with Plotly charts and a playground of examples with precomputed SHAP.
  • Python
  • XGBoost
  • SHAP
  • FastAPI
  • Google Apps Script
  • Plotly

BeaconIQ

BLE Indoor Positioning System

  • Developed an Android indoor positioning app based on BLE beacon signals: RSSI-to-distance conversion, Kalman filtering, a trilateration solver and real-time 2D visualization with configurable parameters.
  • Two-phase testing architecture with a GAS backend that records each session's data in Google Sheets for model calibration and analysis.
  • Signalion test lab (own code): a pure-Java positioning core with no Android dependencies, 1D/2D Kalman filters and Levenberg–Marquardt trilateration, covered by 161 automated tests (136 core, 25 app).
  • On-device testing found that on Android 12+, declaring the BLE scan permission with neverForLocation causes the system to silently drop iBeacon advertisements; the app requests precise location on all versions.
  • Android/Java
  • AltBeacon
  • Google Apps Script (GAS)
